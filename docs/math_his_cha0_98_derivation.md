## ⚖️ 0.98.1 先讲最重要的一件事：推导只有两类合法动作

任何一条推导链，无论多长多吓人，每一步都只可能是下面两类之一：

| 类型 | 做什么 | 信息量 | 可逆？ | 例子 |
|------|-------|-------|-------|------|
| **A. 恒等变换**（保真重写） | 换一件衣服，内容一模一样 | 不变 | ✅ 可逆 | 移项、配方、通分、换元、取对数、展开、因式分解 |
| **B. 引入新信息**（加公理/假设/近似） | 往系统里塞进一条新事实 | **增加** | ❌ 不可逆 | 代入物理定律、守恒律、边界条件、$v\ll c$ 的近似、独立性假设 |

**推导之所以能"凭空"得到新公式，全部的魔法都在 B 类动作里；而 A 类动作只负责让 B 塞进来的信息暴露出来。**

这条区分极其实用。你读任何一段推导时，逐行问一句："**这一步是 A 还是 B？**"

- 如果是 **A**，你有权要求它**可验证**：两边应该恒等，SymPy 一行 `simplify(lhs - rhs) == 0` 就能查。
- 如果是 **B**，你有权要求它**报账**：新塞进来的假设是什么？在什么条件下成立？丢掉的是几阶小量？

**课本最大的罪过，是把 B 类动作伪装成 A 类。** "注意到……" 四个字后面，往往藏着一整条物理定律。

### 顺带澄清：等号 $=$ 有四种完全不同的意思

推导中一半的困惑来自这里 —— 同一个 $=$ 在干四件事：

| 写法 | 意思 | 你该做的动作 | 代码类比 |
|------|------|------------|---------|
| $s := vt$、$\triangleq$ | **定义**：左边是我刚起的新名字 | 不用"解"它，直接展开替换 | `s = v * t` 赋值 |
| $\sin^2\theta+\cos^2\theta \equiv 1$ | **恒等式**：对所有取值都成立 | 可以随时正着用、反着用 | 一条重写规则 |
| $x^2+px+q = 0$ | **方程**：只对某些 $x$ 成立，是待解的**约束** | 求解，别当恒等式乱代 | `assert` / 约束求解 |
| $\sin x \approx x$ | **近似**：在某条件下成立，有误差阶 | 记账！记住 $O(x^3)$ 被丢了 | 有损压缩 |

> 看到 $=$ 先分类。把方程当恒等式用，是初学者最常见的翻车方式。

## 🧰 0.98.2 推导工具箱：十二个动作，覆盖 90% 的推导

这些就是**你能做的全部合法动作**。数学家不是有一万个技巧，是这十二个动作用了一辈子。

| # | 动作 | 它到底在干什么（结构含义） | 历史出处 | 代码 / 检查 |
|---|------|---------------------------|---------|------------|
| 1 | **两边同做一件事** | 保持等价关系的群作用 | 花拉子米 *al-Jabr* 820（"移项"就是这个词） | `Eq(lhs+d, rhs+d)` |
| 2 | **配方法** | 二次型的正交对角化 | 巴比伦泥板 BM 13901（前 1800） | `sp.complete_square` / 手工 |
| 3 | **换元** $x = g(u)$ | 换坐标系，把陌生结构映到已知结构 | 费马 1630s、欧拉 1750s | `expr.subs(x, g(u))`，**别忘雅可比** |
| 4 | **乘以聪明的 1 / 加 0** | 在不改值的前提下制造出可配对的结构 | 分母有理化、共轭相乘 | $\frac{a-b}{1}\cdot\frac{a+b}{a+b}$ |
| 5 | **取对数 / 取指数** | 在 $(\mathbb{R}^+,\times)\leftrightarrow(\mathbb{R},+)$ 之间切换 | 纳皮尔 1614 | `sp.expand_log(..., force=True)` |
| 6 | **级数展开** | 在一点附近把函数换成多项式 | 泰勒 1715、麦克劳林 1742 | `sp.series(f, x, 0, n)` |
| 7 | **微分 / 积分两边** | 用"变化率"这条通道搬运信息 | 牛顿、莱布尼茨 1666–1675 | `sp.diff` / `torch.autograd.grad` |
| 8 | **量纲分析** | 用单位的对称性直接锁死公式骨架 | 傅里叶 1822、瑞利 1877、白金汉 1914 | 解指数的线性方程组 |
| 9 | **对称性 / 不变量** | 用"这个量不变"消掉未知数 | 克莱因 1872、诺特 1918 | 守恒量的 `assert` |
| 10 | **取极限 / 极端情形** | 让高阶项自动死掉 | 柯西 1821、魏尔斯特拉斯 1860s | `sp.limit` |
| 11 | **归纳 / 递推** | 用良序原理把无穷降为有限 | 帕斯卡 1654 | 递归 + 记忆化 |
| 12 | **反着用已知定理** | 把目标形状当作模板去凑 | 波利亚"逆向工作法" | 从终点写起 |

其中 **#1 恒等变换** 和 **#3 换元** 是绝对主力，值得单独说清楚。

### 恒等变换的本质：只有"换衣服"的权利，没有"换人"的权利

$$\underbrace{x^2 + px + q}_{\text{原式}} \;=\; \underbrace{\Big(x+\tfrac{p}{2}\Big)^2 - \tfrac{p^2}{4} + q}_{\text{配方后}}$$

这一步**没有新增任何信息** —— 两个表达式对任意 $x$ 都相等。它唯一做的事，是把 $x$ 从**两个地方**（$x^2$ 里一次、$px$ 里一次）**收拢到一个地方**。

**"把未知数逼到只出现一次"** —— 这就是配方法真正的目的，也是巴比伦人 3800 年前在泥板上干的事。一旦 $x$ 只出现一次，反解就是纯机械的开方。

```python
import sympy as sp

x, p, q = sp.symbols('x p q')
expr   = x**2 + p*x + q
square = (x + p/2)**2 - p**2/4 + q

# A 类动作的验收标准：差恒为 0，一行代码可查
print(sp.simplify(expr - square))        # 0   ✓ 恒等变换成立
print(sp.solve(expr, x))
# [-p/2 - sqrt(p**2 - 4*q)/2, -p/2 + sqrt(p**2 - 4*q)/2]
```

> **心法**：看到未知数出现在多处，第一反应就是"能不能把它们合并成一处"。
> 配方、通分、因式分解、三角恒等式、对数换底 —— 全是同一个动机的不同外衣。

### 换元的本质：换一副坐标系，让难题在新坐标下变成简单题

换元不是"设 $u=\ldots$"这种考试技巧，它是**微分同胚**的初等版本：**同一个对象，换一张地图去看。**

判断一个换元好不好，只有一条标准：**换完之后，结构变简单了吗？**

| 换元 | 从什么变成什么 | 为什么变简单 |
|------|--------------|------------|
| $x = \tan\theta$ | $\frac{1}{1+x^2}$ → $1$ | 三角恒等式吃掉了平方和 |
| 直角坐标 → 极坐标 | $e^{-x^2-y^2}$ → $e^{-r^2}\cdot r$ | 多出来的 $r$ 恰好是 $e^{-r^2}$ 的导数因子 |
| $\beta = \tanh\theta$（快度） | $\sqrt{\frac{1-\beta}{1+\beta}}$ → $e^{-\theta}$ | 根号变指数，速度叠加变**加法** |
| $u = e^x$ | 指数方程 → 多项式方程 | 把超越结构降为代数结构 |
| 生成函数 $\sum a_n x^n$ | 数列 → 解析函数 | 递推关系变成代数方程 |

**换元最容易犯的错，是忘了坐标变换会改变"体积元"**（雅可比行列式）：

```python
import sympy as sp

r, th = sp.symbols('r theta', positive=True)

# ✅ 正确：极坐标下 dx dy = r dr dθ，那个 r 不是装饰品
I2 = sp.integrate(sp.exp(-r**2) * r, (r, 0, sp.oo)) * sp.integrate(1, (th, 0, 2*sp.pi))
print(I2, sp.sqrt(I2))        # pi   sqrt(pi)      ← 高斯积分 = √π

# ❌ 错误：漏掉雅可比 r
I2_bad = sp.integrate(sp.exp(-r**2), (r, 0, sp.oo)) * 2*sp.pi
print(sp.simplify(I2_bad))    # pi**(3/2)          ← 差了一个因子，全盘皆错
```

> $\det J$ 就是 Chapter 0.5.4 表里那个"$n$ 维体积的有向倍率"。**换元忘雅可比 = 换了尺子却没换刻度。**

## 🌟 0.98.3 主线案例：亲手推出 $E = mc^2$

现在用上面的工具箱，完整走一遍人类最有名的那个公式。按本项目的规矩（Chapter 0.7）：**现象 → 模拟 → 拆解 → 公式。**

### Step 0 · 先说清楚：这个公式解决的是哪个真实问题

1905 年之前，有一件事让物理学家很不舒服：**光有没有"重量"？**

- 1862 年，**麦克斯韦**从他的方程组算出：光照到物体上会**推**它一下 —— 辐射压 $P = I/c$。
- 1900 年，**列别捷夫**在莫斯科用扭秤**真的测到了**这个推力（1901–1903 年尼科尔斯与赫尔也独立测到）。
- 于是问题变得尖锐：光携带**动量** $p = E/c$。可动量按牛顿的说法是 $mv$ —— **那光的 $m$ 是多少？**

这就是 $E=mc^2$ 要回答的问题。**它不是"关于原子弹的公式"，它是"光有没有惯性"这个问题的答案。**

顺带一提，这也不是爱因斯坦一个人的灵感：J.J. 汤姆孙（1881）算过带电球的"电磁质量"，庞加莱（1900）写下过辐射的"虚拟质量" $E/c^2$，哈森诺尔（1904）算过空腔辐射的惯性。**爱因斯坦的贡献是把它从"电磁现象的一个怪癖"提升成"对一切能量都成立的普遍原理"。**

### Step 1 · 现象先行：先用代码看看"辐射会不会让物体变轻"

```python
import torch

c = 299_792_458.0                      # m/s

# 现象①：广岛原子弹 15 kt TNT ≈ 6.3e13 J，对应多少质量？
E_hiroshima = 15 * 4.184e12
print(E_hiroshima / c**2 * 1000)       # 0.698  克   ← 不到一枚硬币

# 现象②：太阳每秒辐射 3.828e26 W，每秒"变轻"多少？
print(3.828e26 / c**2)                 # 4.26e9  kg/s ← 每秒烧掉 426 万吨

# 现象③：一杯 300 mL 的水烧开（ΔT=80K），质量增加多少？
print(0.3 * 4186 * 80 / c**2)          # 1.12e-12 kg  ← 万亿分之一克，测不到
```

**这三个数字就是全部动机**：能量和质量之间有一个**兑换率**，而且这个汇率大到离谱（$c^2 \approx 9\times10^{16}$）。日常生活中看不到它，只是因为汇率太高、零钱太小。

现在的任务是：**把这个汇率推出来。**

### Step 2 · 路线 A：爱因斯坦 1905 年那三页纸

1905 年 9 月 27 日，《物理学年鉴》收到爱因斯坦一篇只有三页的补遗：**《物体的惯性与其所含能量有关吗？》**

> **历史细节**：爱因斯坦原文里用 $L$ 表示能量、$V$ 表示光速，结论写作 "$m$ 减少 $L/V^2$"。
> **他一生中从未在那篇论文里写下过 "$E=mc^2$" 这个式子本身** —— 这个写法是后人整理出来的。

他的思想实验只有一句话：

> **一个静止的物体，同时朝左右两边各发射一束能量为 $E/2$ 的光。**

为什么是"两束、反向、等能量"？—— 这是 **动作 #9（对称性）**：左右对称让**动量恰好抵消**，物体在原参考系里**保持静止**。于是"动能变化"这个干扰项被彻底清除，只剩下我们想要的量。

**这就是推导中最值得学的一招：先用对称性把不想要的自由度杀掉。**

现在换到一个以速度 $v$ 运动的参考系 $S'$ 去看同一件事。光的能量会因为多普勒效应改变：

```python
import sympy as sp

E  = sp.Symbol('E', positive=True)
th = sp.Symbol('theta', positive=True)      # 换元 #3：快度 rapidity，令 β = tanh θ
beta = sp.tanh(th)

# 相对论多普勒因子（迎向 / 背向）
D_fwd = sp.sqrt((1 - beta) / (1 + beta)).rewrite(sp.exp)
print(sp.simplify(D_fwd))                   # exp(-theta)   ← 根号变成了指数！

# 在 S' 系里，两束光的总能量
E_prime = sp.simplify((E/2 * sp.sqrt((1-beta)/(1+beta))
                     + E/2 * sp.sqrt((1+beta)/(1-beta))).rewrite(sp.exp))
print(E_prime)                              # E*cosh(theta)
print(sp.simplify(E_prime - E*sp.cosh(th))) # 0   ✓
```

看清这里发生了什么 —— **换元 $\beta = \tanh\theta$ 把两个丑陋的根号变成了 $e^{-\theta}$ 和 $e^{+\theta}$，而它们的和按定义就是 $2\cosh\theta = 2\gamma$。**
一个换元，把整段代数化简变成了"查一次双曲函数的定义"。这就是 **动作 #3** 的威力。

于是：

| 参考系 | 物体损失的能量 |
|-------|--------------|
| 静止系 $S$ | $E$ |
| 运动系 $S'$ | $\gamma E$，其中 $\gamma = \cosh\theta = 1/\sqrt{1-v^2/c^2}$ |

两个系里损失的能量**不一样**，差值是 $(\gamma - 1)E$。可是物体的速度 $v$ 一点没变（左右对称，没被推动）。
**那这个差值只能记在"动能"头上 —— 而动能是 $\frac12 m v^2$，$v$ 不变，就只能是 $m$ 变了。**

现在做 **动作 #6（级数展开）**，因为我们只关心 $v \ll c$ 的低速极限：

```python
import sympy as sp

E, b = sp.Symbol('E', positive=True), sp.Symbol('beta', positive=True)
gamma = 1 / sp.sqrt(1 - b**2)

dK = sp.series((gamma - 1) * E, b, 0, 5)
print(dK)          # E*beta**2/2 + 3*E*beta**4/8 + O(beta**5)
```

$$\Delta K = (\gamma-1)E = \frac{E}{2}\frac{v^2}{c^2} + O\!\left(\frac{v^4}{c^4}\right)$$

把它和经典动能 $\frac{1}{2}mv^2$ 对照 —— **两边都是 $\frac12(\cdot)v^2$ 的形状，那个括号就必须相等**：

$$\frac{1}{2}\left(\frac{E}{c^2}\right)v^2 = \frac{1}{2}(\Delta m)\, v^2 \quad\Longrightarrow\quad \boxed{\Delta m = \frac{E}{c^2}}$$

**推导完毕。** 现在回头给每一步贴标签：

| 步骤 | 动作类型 | 用了工具箱第几式 |
|------|---------|----------------|
| 朝左右各发一束光 | **B**（引入设定） | #9 对称性 —— 杀掉动量这个自由度 |
| 换到 $S'$ 系，用多普勒 | **B**（引入物理定律） | 相对论运动学 |
| $\beta = \tanh\theta$ | **A** 恒等变换 | #3 换元 —— 根号 → 指数 |
| 求和得 $\gamma E$ | **A** 恒等变换 | 双曲函数定义 |
| 展开到 $v^2$ 阶 | **B**（近似，有损！） | #6 级数展开 —— 丢掉 $O(v^4)$ |
| 与 $\frac12 mv^2$ 比对 | **B**（引入经典力学） | #12 逆向工作 —— 拿目标形状当模板 |

> **诚实地报一笔账**：1952 年赫伯特·艾夫斯公开指责这个推导是**循环论证** —— 因为它中途借用了经典动能 $\frac12mv^2$。后来 Stachel & Torretti（1982）等人做了详细辩护，认为艾夫斯的指控本身有误。
> 这场争论本身才是最好的教材：**一条推导的价值，不在于结论对不对，而在于每一步的前提能不能被公开审查。** 结论正确、推导有洞，在物理史上很常见。

### Step 3 · 路线 B：光子盒 —— 五行代数，最物理

1906 年爱因斯坦自己给了一个更漂亮的版本。用的是一条比动能更硬的原理：**在没有外力时，系统质心不能自己移动**（这条来自动量守恒，是 **动作 #9**）。

```
   ┌───────────────────────────────┐
   │ ●→~~~~~~~~~~~~~~~~~~~~~~~~~→  │   左壁发出光子（能量 E，动量 E/c）
   │                               │   盒子（质量 M）向左反冲
   └───────────────────────────────┘
   ←─────────── L ───────────────→
```

```python
import sympy as sp

M, L, c, E, m = sp.symbols('M L c E m', positive=True)

v  = E / (M * c)          # ① 动量守恒：盒子反冲速度（光子动量 p = E/c）
t  = L / c                # ② 光子飞越盒长所需时间
dx = v * t                # ③ 这段时间里盒子后退的距离
print(sp.simplify(dx))    # E*L/(M*c**2)

# ④ 质心不动：若光子等效携带质量 m，它向右搬运 m·L，必须抵消盒子向左的 M·Δx
print(sp.solve(sp.Eq(m * L, M * dx), m))    # [E/c**2]   ✓
```

**四行，没有相对论，没有级数展开，没有借用动能。** 只用了动量守恒 + 质心定理 + 光的动量 $p=E/c$。

对比两条路线，能看出推导的一个重要事实：**同一个结论可以有完全不同的推导路径，而路径的选择决定了你需要预设多少东西。** 路线 B 的前提更少、更硬，所以它更有说服力。

> 找到"前提更少的那条路"，是数学品味的核心。**推导不是能走通就行，是要走得便宜。**

### Step 4 · 路线 C：从完整能量表达式看 $E=mc^2$ 的真身

真正的相对论能量是 $E = \gamma m c^2$。展开它：

```python
import sympy as sp

m, v, c = sp.symbols('m v c', positive=True)
E_tot = m * c**2 / sp.sqrt(1 - v**2/c**2)
print(sp.series(E_tot, v, 0, 6))
# c**2*m + m*v**2/2 + 3*m*v**4/(8*c**2) + O(v**6)
```

$$E = \underbrace{mc^2}_{\text{静止能}} + \underbrace{\tfrac12 mv^2}_{\text{牛顿动能}} + \underbrace{\tfrac38\frac{mv^4}{c^2}}_{\text{相对论修正}} + \cdots$$

这一行揭穿了三件事：

1. **$E = mc^2$ 只是完整公式的零阶项** —— 是 $v=0$ 时的特例，不是全貌。
2. **牛顿动能 $\frac12mv^2$ 自动作为一阶项掉出来** —— 新理论必须在旧理论的地盘上退化成旧理论（**对应原理**，玻尔 1920）。这是**验收新公式的黄金标准**。
3. 那个 $\frac38 mv^4/c^2$ 是可测的：它正是水星近日点进动、GPS 卫星钟差这类修正的来源。

> **推导完一个新公式，第一件事永远是：让参数退到极限，看它能不能变回你已知的旧公式。** 变不回去 —— 你推错了。

## 🔧 0.98.4 三个短案例：不同招式的示范

### 案例一：量纲分析 —— 不推导，直接"猜"出单摆周期

物理学家有个作弊技巧：**在动笔之前，用单位把公式的骨架锁死。**

单摆周期 $T$ 可能依赖：绳长 $L$（米）、重力 $g$（米/秒²）、摆球质量 $M$（千克）。设 $T = L^a g^b M^d$，那么单位必须两边对齐：

```python
import sympy as sp

a, b, d = sp.symbols('a b d')
sol = sp.solve([sp.Eq(a + b, 0),     # 长度[m]  的指数必须为 0
                sp.Eq(-2*b, 1),      # 时间[s]  的指数必须为 1
                sp.Eq(d, 0)],        # 质量[kg] 的指数必须为 0
               [a, b, d])
print(sol)        # {a: 1/2, b: -1/2, d: 0}
```

$$T \propto \sqrt{L/g}$$

**一行线性方程组，直接得到了公式的全部形状**，而且顺带证明了**周期与质量无关**（伽利略 1602 年在比萨大教堂盯着吊灯看出来的那件事）。量纲分析给不出的，只有那个无量纲常数 $2\pi$ —— 那要真的解微分方程才知道。

> **量纲分析 = 用"单位"这个对称性，把无穷维的函数空间压缩到几个待定指数。** 性价比最高的动作，没有之一。

### 案例二：小角近似 —— 一次诚实的"有损压缩"

单摆的真实方程是 $\ddot\theta = -\frac{g}{L}\sin\theta$，**没有初等函数解**。课本上那个 $T = 2\pi\sqrt{L/g}$ 是怎么来的？靠一次 **B 类动作**：

$$\sin\theta = \theta - \frac{\theta^3}{6} + O(\theta^5) \;\approx\; \theta$$

**这一步不可逆，必须报账**：丢掉的是 $\theta^3/6$。那么误差有多大？直接数值验一下：

```python
import torch

def period_numeric(theta0, L=1.0, g=9.81, dt=1e-5):
    """现象先行：真的把单摆跑一遍，量出它的周期（不解方程，只模拟）"""
    th, om = torch.tensor(theta0), torch.tensor(0.0)
    t, prev = 0.0, th
    while True:                                   # 跑到摆回原处（半个周期）
        om = om - (g / L) * torch.sin(th) * dt
        th = th + om * dt
        t += dt
        if th * prev < 0:                         # 过了平衡位置 = 1/4 周期
            return 4 * t
        prev = th

import math
T_small = 2 * math.pi * math.sqrt(1.0 / 9.81)
for th0 in (0.1, 0.5, 1.0, 2.0):
    T = period_numeric(th0)
    print(f"θ₀={th0:>4}: 真实 {T:.4f}s  小角公式 {T_small:.4f}s  误差 {(T/T_small-1)*100:>6.2f}%")
```

跑出来的真实数字：

```
θ₀= 0.1: 真实 2.0073s  小角公式 2.0061s  误差   0.06%
θ₀= 0.5: 真实 2.0379s  小角公式 2.0061s  误差   1.59%
θ₀= 1.0: 真实 2.1391s  小角公式 2.0061s  误差   6.63%
θ₀= 2.0: 真实 2.6659s  小角公式 2.0061s  误差  32.89%
```

小角度下（$\theta_0=0.1$）误差只有 0.06%，而摆到 2 弧度（约 115°）时误差已经 33% —— **那个被丢掉的 $\theta^3/6$ 回来讨债了。**

**近似不是"约等于"三个字就完事了，它是一笔有明确利率的贷款。** 好的推导会告诉你利率是多少、什么时候必须还。

### 案例三：反向传播 —— 推导中的"复用"原则

链式法则 $\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial y}\frac{\partial y}{\partial h}\frac{\partial h}{\partial w_1}$ 早在莱布尼茨手里就有了。那为什么反向传播要等到 1970（Linnainmaa）/ 1986（Rumelhart 等）才被当回事？

**因为真正的洞见不在链式法则本身，而在"从哪一头开始乘"。**

```python
import torch

# 一个 3 层网络：L ← y ← h2 ← h1 ← w
# 链式法则说：dL/dw = (dL/dy)(dy/dh2)(dh2/dh1)(dh1/dw)
# 乘法满足结合律 —— 所以从左往右乘、从右往左乘，答案完全一样。
# 但代价完全不一样：
#
#   从右往左（前向模式）：每个参数都要重算一遍整条链   → 代价 ∝ 参数个数
#   从左往右（反向模式）：一次算完，所有参数共享中间结果 → 代价 ∝ 1 次前向
#
# 神经网络有 1e9 个参数、1 个 loss —— 所以必须从 loss 那头开始往回乘。

w = torch.randn(4, 4, requires_grad=True)
x = torch.randn(4)
loss = torch.sigmoid(w @ torch.tanh(w @ x)).sum()
loss.backward()                       # ← 这一行的全部内容：结合律 + 选对乘法顺序
print(w.grad.shape)                   # torch.Size([4, 4])
```

> **推导的一条隐藏原则：当一个表达式可以用多种顺序求值时，顺序本身就是一个可优化的自由度。**
> 动态规划、矩阵链乘、`einsum` 的收缩顺序、反向传播 —— 全是同一件事。**恒等变换不改变结果，但会改变代价。**

## 🚨 0.98.5 五个经典陷阱：推导是怎么坏掉的

| 陷阱 | 长什么样 | 为什么坏 | 防御 |
|------|---------|---------|------|
| **除以可能为零的量** | $a^2=ab \Rightarrow a=b$ | 两边除以 $(a-b)$，而它正好是 0 | 每次消去都问"它可能为零吗" |
| **换元忘雅可比** | $\iint \to \int\int$ 时漏掉 $r$ | 坐标变了，体积元也变了 | 换元后先做数值对拍 |
| **近似阶数不齐** | 保留了 $v^2$ 却丢了另一个 $v^2$ 项 | 精度被最差的那一项拖死 | 全程统一展开到同一阶 |
| **随意交换极限 / 求和次序** | $\sum\int \to \int\sum$ | 需要一致收敛，否则可能发散 | 有限项截断后数值验证 |
| **循环论证** | 用结论的推论去证结论 | 什么也没证明 | 画依赖图：每条前提从哪来 |

第一个陷阱的经典形式（"1 = 2 的证明"），值得亲手跑一遍看它在哪一步崩掉：

```python
import sympy as sp

a, b = sp.symbols('a b')
# 设 a = b，则：a² = ab → a² - b² = ab - b² → (a+b)(a-b) = b(a-b) → a+b = b → 2b = b → 2 = 1
step = sp.Eq((a + b) * (a - b), b * (a - b))
print(sp.simplify(step.lhs - step.rhs).subs(a, b))   # 0  —— 到这一步都是对的

# 崩溃点：两边同除 (a-b)。但 a = b ⇒ a-b = 0
print(sp.solve(sp.Eq(a - b, 0), a))                  # [b]   ← 除数恒为零
```

> **每一次"两边同除"，都是一次没写出来的 `assert divisor != 0`。** 大多数假证明都死在这一行缺失的断言上。

## ✅ 0.98.6 验收三板斧：怎么知道自己推对了

推导和写代码一样，**不做测试的推导等于没推**。三道防线，从便宜到贵：

### 第一道：量纲检查（0 秒，先做）

加号两边必须同量纲，$\exp/\log/\sin$ 的宗量必须无量纲（Chapter 0.6 Step 4）。
$E = mc^2$ 通过：$[\text{kg}]\cdot[\text{m/s}]^2 = \text{kg·m}^2/\text{s}^2 = \text{J}$ ✓。**这一步不需要理解公式就能做，却能抓住一半的低级错误。**

### 第二道：极限退化（10 秒）

把参数推到极端，看它退化成什么已知的东西：

| 极限 | 应该退化成 |
|------|-----------|
| $v \to 0$ | $\gamma mc^2 \to mc^2 + \frac12mv^2$（牛顿力学）✓ |
| $\hbar \to 0$ | 量子 → 经典 |
| $T \to 0$ | softmax → argmax（Chapter 0.6 Step 5）|
| $n \to \infty$ | 二项分布 → 高斯（棣莫弗 1733）|

**新公式必须在旧公式的地盘上变回旧公式。** 这条叫对应原理，是物理学家最信任的检查。

### 第三道：数值对拍（1 分钟，最硬）

**手推的闭式解 vs 暴力数值解，两条完全独立的路径必须给出同一个数。**

```python
import sympy as sp, torch

# 手推：高斯积分 ∫e^{-x²}dx = √π（靠极坐标换元推出来的）
x = sp.Symbol('x')
closed = sp.integrate(sp.exp(-x**2), (x, -sp.oo, sp.oo))
print(closed)                                       # sqrt(pi)

# 暴力：直接梯形法数值积分，不用任何推导
xs = torch.linspace(-8, 8, 200_001)
numeric = torch.trapz(torch.exp(-xs**2), xs)
print(numeric.item(), float(closed.evalf()))        # 1.77245378  1.77245385  ✓
```

> **对拍是唯一无法自欺欺人的验收。** 你可以说服自己"这一步应该没问题"，但你说服不了一个不同意的数字。
> 本项目所有推导类脚本都遵守一条硬规矩：**符号推导 + 数值模拟 + 库函数，三者必须互相对拍。**

## 🧠 0.98.7 选路的心法：大师为什么"知道下一步走哪"

工具箱有十二个动作，那**每一步该选哪一个？** 这是初学者和熟手真正的差距。四条可训练的启发式：

### 1. 先盯着终点看：目标形状驱动（波利亚逆向工作法）

推 $E=mc^2$ 时，我们知道终点长成 "质量 = 能量 ÷ 某个东西"。
于是**整条推导都在朝"凑出一个 $\frac12(\cdot)v^2$ 的形状"努力** —— 因为只要凑出这个形状，括号里的东西就必须是质量。

> **不知道终点长什么样，就不知道该往哪化简。** 先写下目标形状，再倒着问"什么能变成它"。

### 2. 每一个等式都必须有来源：不是守恒律，就是定义

推导中的等号不会从天上掉下来。逐条追问 "$=$ 从哪来"，答案永远在这四类里：

| 来源 | 例子 |
|------|------|
| **守恒律** | 动量守恒 → 光子盒的反冲；能量守恒 → 热力学第一定律 |
| **对称性** | 左右对称 → 动量抵消；诺特定理 → 每个连续对称给一个守恒量 |
| **定义** | $\gamma :\!= 1/\sqrt{1-\beta^2}$ —— 不用证，是起的名字 |
| **实验事实** | $c$ 是常数；光的动量 $p = E/c$ |

**卡住的时候，就问："我还有哪个守恒律没用上？"** 十有八九答案在那里。

### 3. 数未知数、数方程：先做一次"自由度审计"

$n$ 个未知数需要 $n$ 个独立方程。推导卡住时，先数一数：**是信息不够（要再引入一条物理），还是信息够了但没整理出来（该做 A 类恒等变换）？**

这个判断决定了你接下来是去查物理书，还是去做代数。**分不清这两种"卡住"，就会在错误的方向上耗掉一下午。**

### 4. 先做特例，再做一般

$n=1,2$ 先算；一维先算再推三维；无摩擦先算再加摩擦。
**特例里那个"哦原来是这样"的瞬间，就是一般情形的证明骨架。** 波利亚那句话就是这个意思：解不出来这道题，就先解一道更简单的。

> **一句话总结选路心法**：**盯着终点，查守恒律，数自由度，先做特例。**
> 这四条，就是"灵感"被拆开之后剩下的全部东西。
